# 🚀 Momentum – Smart Task Management App

Momentum is a modern, responsive task management web application designed to help you track progress, manage deadlines, and stay productive.

It combines clean UI design with smart task sorting, visual statistics, and motivational progress tracking — all powered by pure frontend technologies.

---

## 🌐 Live Overview

Momentum allows users to:

- Add tasks with deadlines and priority levels
- Automatically detect overdue tasks
- Track overall completion progress
- View visual analytics using charts
- Store tasks locally in the browser

No backend. No database. No login required.

---

# 📌 Features

## 📝 Task Management
- Add tasks with:
  - Task Name
  - Due Date
  - Priority (Low, Medium, High)
- Mark tasks as completed
- Delete individual tasks
- Clear all tasks (with confirmation modal)

---

## 📊 Smart Dashboard
- Total Tasks
- Completed Tasks
- Pending Tasks
- Overdue Tasks

---

## 📈 Visual Progress Tracking
- Animated progress bar
- Motivational status messages
- Doughnut chart visualization using Chart.js

---

## 🔍 Smart Sorting Logic

Tasks are automatically sorted by:

1. Incomplete tasks first
2. Overdue tasks prioritized
3. Higher priority ranked first
4. Completed tasks moved to bottom

---

## 💾 Persistent Storage

Momentum uses **Browser LocalStorage**, meaning:

- Tasks remain saved after refreshing
- Data stays on the user's device
- No server required

# 🚀 How to Use

### Step 1: Add a Task
- Enter task name
- Select due date
- Choose priority
- Click **Add Task**

### Step 2: Manage Tasks
- Click ✔ to mark complete
- Click 🗑 to delete
- Use search bar to filter tasks

### Step 3: Monitor Progress
- View statistics cards
- Check progress bar percentage
- Analyze doughnut chart
- Get motivational feedback
