About Momentum

Your smart productivity and deadline tracking companion.

📌 What is Momentum?

Momentum is a modern task management web application designed to help you organize, track, and complete your tasks efficiently. It provides visual progress tracking, deadline monitoring, and priority management — all within a clean and responsive interface.

🚀 Key Features

  • ✔ Add tasks with due dates and priority levels
  • ✔ Smart sorting (Overdue → Priority → Completion status)
  • ✔ Real-time search functionality
  • ✔ Visual statistics dashboard
  • ✔ Progress tracking with motivational feedback
  • ✔ Doughnut chart overview of task status
  • ✔ LocalStorage support (your data stays saved in your browser)
  • ✔ Fully responsive design

🛠 How to Use Momentum

  1. Enter your task name.
  2. Select a due date.
  3. Choose priority (Low, Medium, High).
  4. Click Add Task.
  5. Mark tasks complete when finished.
  6. Monitor your progress using the dashboard and chart.

💻 Built With

Momentum is built using:

  • HTML5
  • CSS3 (Modern responsive design)
  • JavaScript (Vanilla JS)
  • Chart.js (for data visualization)
  • Font Awesome (icons)
  • Browser LocalStorage (data persistence)

🎯 Our Vision

We believe productivity tools should be simple, intuitive, and motivating. Momentum is built to reduce clutter and help users stay focused on what matters most — completing tasks and achieving goals.
